Honest build notes

Verify with a local build. Screenshots come from stock Firefox 136 wearing the exact shipped values; the in-tree integration needs ./mach build && ./mach run on your machine for final sign-off.

One vendor step for uBlock Origin. This environment cannot reach addons.mozilla.org, so run python3 browser/extensions/ublock/vendor.py once; the build detects the xpi automatically.

Scramjet proxy: deferred deliberately. It needs a hosted server and targets filter circumvention rather than ad tracking — uBlock Origin plus Firefox’s Enhanced Tracking Protection already cover the privacy goal. If wanted later: an off-by-default setting pointing at a self-hosted instance.

Staying mergeable. Everything lives in new directories; the upstream diff is a handful of one-line registrations tracked in TOUCHED_UPSTREAM_FILES.md.
